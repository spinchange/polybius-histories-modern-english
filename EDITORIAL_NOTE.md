# Editorial Note

This edition is a modern-English working translation of the extant local source corpus for Polybius, *The Histories*.

The source corpus used by this project is stored under `source/` and currently contains Books 1-39. Book 17 has no chaptered Greek text in the local source set and is represented by the note: "Nothing of this book survives." Book 40 and any material beyond Book 39 are not present in the current local source corpus and are not treated here as missing translation.

Each assembled book file is built from the chunk translations under `translations/`. The translation process used the Greek source as the basis and older public-domain English material as a reference crib, not as final wording.

The resulting edition should be read as a project edition of the digitally available extant corpus represented in this workspace, not as a claim that every historically surviving Polybian fragment from every witness has been independently audited outside this source set.

Current verification status:

- Assembled book files exist for Books 1-39.
- Source chapter coverage and assembled chapter headings match for all books in the local source corpus.
- No missing translated chapters were reported by `compare_structure.py`.
- Inline numeric marker cleanup reports no remaining changes needed.
- Book 17 is intentionally a survival note rather than a translated chapter sequence.

## Illustrations and Art Colophon

The illustrations accompanying this edition—including the front and back covers, website hero banners, social cards, ornamental chapter headpieces, and the thirty-nine book frontispiece plates—were generated using Google's Gemini models in a nineteenth-century archaeological folio style, combining fine copperplate engraving and etching linework with restrained watercolor washes on warm parchment. All compositions were directed and verified against third- and second-century BC historical guardrails (concerning Hellenistic Greek, Republican Roman, Carthaginian, Numidian, and Celtic material culture, weaponry, and naval architecture). In harmony with the text of this edition, all original artwork created for this project is dedicated to the public domain under Creative Commons CC0 1.0 Universal.
